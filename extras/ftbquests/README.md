# Clover Magic quests

## You already have a quest book: the advancement screen (key L)
The mod adds a "Clover Magic" tab to the vanilla advancement screen. It is a full quest tree (21 quests) with rewards:
every quest gives items (from loot tables) and experience when you finish it, and pops up a toast. No extra mod needed.
Open it with **L** (Advancements) and click the Clover Magic tab on the left.

## Optional: the same quests in FTB Quests
If you want the quests in FTB Quests as well:
1. Install FTB Quests and its libraries.
2. Copy `clover_magic.snbt` to `config/ftbquests/quests/chapters/`.
3. Every quest there is an **Advancement** task with the same advancement the vanilla quest book uses, and gives experience.
   The items still come from the vanilla advancement rewards, so nothing is given twice.
   (The file was written without FTB Quests available, so a small format fix may be needed: rebuild it by hand with Advancement tasks if it is refused.)
