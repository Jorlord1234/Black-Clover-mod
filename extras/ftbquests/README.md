# Clover Magic quests for FTB Quests

1. Install FTB Quests (and its libraries) in your modpack.
2. Copy `clover_magic.snbt` to `config/ftbquests/quests/chapters/` (create the folders if needed) in your game or server folder.
3. Start the game. If FTB Quests refuses the file, open the quest editor and rebuild the chapter by hand: every quest uses the
   task type **Advancement** with one of the advancements below. (This file was written without FTB Quests available, so a small format fix may be needed.)

## Advancements the mod gives (data/clovermagic/advancement/*.json)
got_grimoire, four_leaf, five_leaf, level_5, level_10, level_15, level_20, spirit_bond, devil_union, magic_knight,
talked_asta, talked_julius, talked_orsi, hobgoblin_slayer, second_grimoire, devil_mark

They are hidden advancements (no popup); any quest mod or datapack can use them as a condition.
